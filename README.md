# Атлас — ИИ-конструктор путешествий

Сервис планирования поездок: вы указываете страну, даты, бюджет и предпочтения — Атлас собирает маршрут по городам, подбирает отели, распределяет бюджет и расписывает каждый день по часам.

![Главная страница Атласа](./docs/home.png)

## Что умеет

- **Маршрут под запрос** — учитывает длительность, бюджет, темп, интересы и пожелания в свободной форме.
- **Города и ночи** — распределяет дни между городами без пустых переездов, показывает причины выбора каждого города.
- **Отели** — подбирает варианты под бюджет и локацию, показывает рейтинг, удобства и итоговую стоимость проживания.
- **Бюджет** — раскладывает сумму на проживание, питание, дорогу, впечатления, сувениры и резерв; суммы сходятся до рубля.
- **План на каждый день** — таймлайн с временем, локациями, стоимостью, погодой и бюджетом дня.
- **Советы и чек-лист** — документы, сборы и локальные подсказки, которые можно отмечать.
- **Сохранение** — маршруты хранятся в `localStorage`, открываются по прямой ссылке и пересобираются одним нажатием.
- **Демо-режим** — без ключа GigaChat работает собственный движок на курируемом каталоге из 16 стран и 50 городов.

## Стек

- React 18 + TypeScript
- Redux Toolkit + React Router
- Chakra UI 2, Emotion, Framer Motion
- LangChain + GigaChat (`langchain-gigachat`) для ИИ-агента
- Express — заглушки API в `stubs/api`
- BroJS CLI (`@brojs/cli`) — альтернативная сборка/раздача SPA
- ESLint 9, Vitest-совместимые тесты на Node Test Runner

## Быстрый старт

```bash
npm install
npm start
```

Приложение откроется на [http://127.0.0.1:5173](http://127.0.0.1:5173). Дев-сервер на Express одновременно отдаёт Vite и API `/api/*`.

### Переменные окружения

Скопируйте `.env.example` в `.env` (файл читается сервером через окружение процесса):

```bash
GIGACHAT_CREDENTIALS=ваш_ключ
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat
```

Без ключа приложение работает в демо-режиме: маршруты собирает Atlas Engine, а в интерфейсе это честно отмечено бейджем «Демо-движок». С ключом GigaChat используется как ИИ-куратор: выбирает города и отели из каталога, предлагает темы дней и персональные советы. При ошибке или таймауте API автоматически откатывается на демо-маршрут.

### BroJS

В проекте есть `bro.config.js` и зависимость `@brojs/cli`. Для проверки альтернативного контура:

```bash
npm run brojs:build
npm run brojs:serve
# http://localhost:8099/atlas-travel
```

Основной контур (`npm start`) использует тот же `stubs/api` и не зависит от платформенного `fire.app`.

## API

Все маршруты доступны через Express-роутер `stubs/api/index.js`, смонтированный на `/api`.

| Метод | Путь | Описание |
| --- | --- | --- |
| `GET` | `/api/health` | Статус, наличие GigaChat, число направлений |
| `GET` | `/api/countries` | Список направлений и подборка для главной |
| `GET` | `/api/countries/:id` | Города и отели конкретной страны |
| `POST` | `/api/trips/generate` | Собрать маршрут по заявке |
| `GET` | `/api/trips/:id` | Получить ранее собранный маршрут |

Пример запроса:

```json
{
  "country": "georgia",
  "startDate": "2027-05-12",
  "endDate": "2027-05-19",
  "budget": 180000,
  "travelers": 2,
  "interests": ["Гастрономия", "Природа"],
  "pace": "balanced",
  "notes": "Без музеев, больше природы"
}
```

## Структура

```text
src/
  components/
    art/          — процедурные иллюстрации направлений
    generation/   — экран сборки маршрута
    home/         — карточки направлений
    layout/       — навбар, футер, оболочка
    planner/      — форма: страна, даты, бюджет, темп, интересы
    trip/         — герой, карта, отели, бюджет, дни, советы
    ui/           — иконки, кольцо бюджета
  data/           — статический fallback направлений
  pages/          — главная, маршрут, мои поездки, 404
  services/       — API-клиент и localStorage
  store/          — Redux Toolkit slices и thunk
  utils/          — форматирование, валидация
stubs/api/
  catalog.js      — 16 стран, 50 городов, отели и впечатления
  generator.js    — движок маршрута, бюджета и плана по дням
  ai.js           — промпт и интеграция GigaChat через LangChain
  index.js        — Express-роутер
server/index.mjs  — Vite middleware + API + production-раздача
```

## Как считается маршрут

1. Валидация дат, бюджета и числа путешественников.
2. Выбор страны (или подбор под сезон и бюджет для «Удивите меня»).
3. Распределение ночей между городами с учётом темпа.
4. Подбор отелей под долю бюджета на проживание.
5. Расчёт категорий бюджета; сумма всегда равна введённой.
6. Генерация таймлайна: переезды, завтраки, впечатления, ужины, погода.
7. Если настроен GigaChat — города, отели, темы дней и советы обогащаются моделью; иначе используется курируемый каталог.

## Тесты

```bash
npm test
```

Проверяются сумма бюджета, распределение ночей, короткие поездки, режим «Удивите меня», применение AI-плана и парсинг JSON из ответа GigaChat.

## Ограничения демо

- Цены, рейтинги и время работы — ориентировочные и не являются офертой.
- Бронирование отелей и билетов не выполняется.
- Маршруты хранятся в браузере; серверный кеш живёт до перезапуска процесса.
- Для реального GigaChat нужен ключ и доступ к API; проверка TLS отключается только через `GIGACHAT_VERIFY_SSL=false` для локальной разработки.
